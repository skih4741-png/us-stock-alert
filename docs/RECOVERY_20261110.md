# 운영 장애 복구 2.25.1

## 수정과 검증 범위

| 문제 | 변경 | 검증 |
|---|---|---|
| GitHub/시트/앱 상태 불일치 | 핵심 실패·부분 실패·건너뜀을 구분하고 CLI 실패 코드 전파 | Python 회귀 테스트 |
| 상태 기록 저장 실패가 숨겨짐 | 저장 오류 전파, health 저장 실패 시 앱 기록 실패로 보정 | 저장 실패 주입 테스트 |
| 종료된 모델에 반복 요청 | Groq GPT OSS 20B 대체, OpenRouter 무료 라우터, 실패 모델 격리 | 응답 코드 모의 테스트 |
| 입력 초과·일시 제한 | 입력/출력 한도, 413 축소 1회, 429 대기 상태 후 재사용 | Python/Apps Script 회귀 테스트 |
| 포트폴리오 null 날짜 비교 | 날짜 정규화, 숫자 계산 상태 별도 보고 | null 저장 데이터 회귀 테스트 |
| 시트 설정 무시 | 공급자/모델/SEC 설정 허용 목록 등록 | 설정 적용 테스트 |
| 긴 분석이 다른 요청 차단 | 읽기는 전역 잠금 밖, 쓰기 잠금과 인증은 유지 | Apps Script VM 테스트 |
| 조회가 시트 생성/헤더 수정 | 읽기에서는 없는 시트 빈값 반환 | 최초 조회 테스트 |
| 앱 자료가 저장 도중 비어짐 | clear 후 update를 단일 update로 변경, 남은 행은 같은 요청에서 비움 | 저장소 가짜 객체 테스트 |
| 느린 응답과 불확실한 쓰기 재전송 | 응답 시간 제한, 조회만 재시도 | 프런트엔드 API 회귀 테스트 |
| 화면과 서버 버전 불일치 | 관리자 화면에 양쪽 버전과 불일치 표시 | 버전 전달 테스트 |

모의매매 주문 규칙, 위험 상한, 실전 주문 비활성 정책은 변경하지 않았습니다.
기존 테스트의 폐기 모델, 제거된 중복 카드, 과거 엄선 기준, 위험 상한을 넘는 예제를 현행 동작에 맞췄습니다.

## 배포 구성

1. GitHub main: Python 예약 작업 및 docs/ 화면.
2. Google Apps Script: `apps_script/Code.gs`를 해당 프로젝트에 반영하고 **기존 웹 앱 배포를 새 버전으로 수정**합니다. 기존 `/exec` URL을 유지합니다.
3. Script Properties의 키는 기존 값을 유지합니다. GitHub Secrets와 별도입니다. 키 값을 대화나 저장소에 넣지 않습니다.
4. 서버 공개 상태 응답의 `serverVersion`과 앱 관리자 화면의 서버 버전이 **2.25.1**인지 확인합니다.
5. GitHub Actions의 **운영 기능 읽기 점검**을 실행합니다. 거래/알림 없이 저장 자료, 가상 입력을 사용한 무료 모델 응답, 서버 버전을 검사합니다.
6. 로그인 후 홈/후보/보유/관심/뉴스/모의투자/운영 점검을 확인합니다. 로그인 성공과 실제 알림 수신은 별도로 검증해야 합니다.

메일은 기존 설정대로 기본 비활성입니다. 원하는 경우 저장소 변수 `MAIL_ENABLED=1`을 사용합니다. 이 변경 자체로 메일을 켜거나 시험 발송하지 않습니다.

## 실행 해석

- CLI 0: 해당 실행 성공 또는 명시적으로 건너뜀.
- CLI 2: 부분 실패·핵심 실패·기록 저장 실패. 이전 매매/알림을 자동 재실행하지 않습니다.
- 앱의 주간 성공률: 건너뜀은 분모에서 제외합니다. 시작되지 않은 예약 실행은 별도 확인이 필요합니다.
- 단위 테스트 통과는 외부 공급자 응답, 로그인, 실제 알림 도착을 보장하지 않습니다.
- `운영 기능 읽기 점검`은 기존 저장 상태가 실패이거나 서버 배포가 구버전이어도 실패합니다. 점검 자체 오류와 실제 기능 이상을 로그의 항목별 결과로 구분합니다.

## 알려진 한계

- 무료 API의 공급/한도는 외부 상태입니다. 모든 공급자가 제한되면 답변을 만들어 정상으로 표시하지 않습니다.
- Apps Script VM 테스트는 실제 배포 환경 실행을 대신하지 않습니다.
- Python의 단일 시트 update는 빈 시트 노출을 줄입니다. 서로 다른 외부 쓰기 주체 간 분산 트랜잭션을 제공하지는 않습니다.
- 서버 장시간 요청은 프런트엔드가 대기를 끝내도 계속 처리될 수 있습니다. 쓰기 결과는 재조회 후 판단합니다.
