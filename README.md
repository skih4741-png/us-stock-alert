# 미국주식 매수·매도 알림

매일 아침(한국 화~토 07:00 실행, 07:30~08:00 도착) 미국 전체 종목을 같은 규칙으로 걸러,
가격대(10달러 단위)마다 매수 후보 3개와 내 보유 종목의 매도 후보를 **슬랙**으로 보내요. (메일도 쓰려면 워크플로에 `MAIL_ENABLED: "1"`을 추가)
깃허브 서버에서 돌아서 내 PC가 꺼져 있어도 멈추지 않아요.

> 규칙에 따른 검토 후보이며 투자 판단과 책임은 본인에게 있습니다. 자동 주문은 하지 않아요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `main.py` | 전체 순서 실행 (아침 리포트 · 장 전 점검 · 장중 감시 · 주간 요약) |
| `universe.py` | 미국 전체 종목 목록 + 기본 거름망 |
| `prices.py` | 가격·재무·실적 일정·뉴스 수집 (야후 파이낸스, 무료) |
| `market.py` | 시장 국면 (상승장·횡보장·하락장) + 매수 쉬는 날 |
| `scoring.py` | 점수 4개(추세·가치·성장·안전) + 판정 + 급등 거름망 |
| `timing.py` | 매수 구간 · 손절 · 1차 목표 · 매도 규칙 |
| `lists.py` | 가격대·예산 분류, 신규 진입·연속 n일·어제에서 빠짐 |
| `explain.py` | Claude 쉬운 설명 · 주의 한 줄 · 위험 뉴스 경고 (판정에는 안 섞음) |
| `notify.py` | 네이버 메일 · 슬랙 발송과 문구 |
| `sheets.py` | 구글 시트 읽기·쓰기 (보유 종목, 설정, 오늘 리스트, 신호 기록, 실행 기록) |
| `backtest.py` | 과거 검증 |
| `app.py` | 웹페이지 (스트림릿, 메뉴 6개) — 앱이 완성되면 정리 예정 |
| `appdata.py` | 앱이 읽는 데이터(오늘 리스트·보유 한 줄 결론·알림 기록)를 시트 '앱 데이터' 탭에 저장 |
| `docs/` | 홈 화면 앱(PWA) · PC 웹사이트. 깃허브 Pages로 배포 |
| `apps_script/Code.gs` | 로그인 서버 (아이디·비밀번호, 임시 비밀번호 메일, 데이터 전달). 구글 시트의 Apps Script에 붙여넣어 배포 |
| `config.py` · `terms.py` | 기본 설정값 · 화면에 쓰는 한국어 |
| `.github/workflows/` | 예약 실행 (아침 리포트, 장중 감시, 주간 요약, 과거 검증) |

## 깃허브 비밀 값 (Settings → Secrets and variables → Actions)

| 이름 | 넣는 값 |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | 구글 서비스 계정 키 파일(.json)의 내용 전체 |
| `SHEET_ID` | 구글 시트 주소의 `/d/` 와 `/edit` 사이 글자 |
| `NAVER_ID` | 네이버 아이디 (예: skih4741) |
| `NAVER_APP_PASSWORD` | 네이버 앱 비밀번호 (로그인 비밀번호 아님) |
| `MAIL_TO` | 받을 메일 주소 (비우면 네이버 메일로) |
| `SLACK_WEBHOOK_URL` | 슬랙 수신 웹훅 주소 |
| `ANTHROPIC_API_KEY` | Claude API 키 (없으면 설명 없이 표만 보내요) |

변수(Variables) `WEB_URL`에 웹페이지 주소를 넣으면 메일 끝에 링크가 붙어요.

## 내 PC에서 시험

```
pip install -r requirements.txt
python main.py daily --limit 200 --dry
```
키가 없으면 `data/local_sheet` 폴더의 CSV를 시트 대신 써요. `--dry`는 보내지 않고 화면에만 보여줘요.

## 처음 할 일

1. 깃허브 Actions → "과거 검증" 실행 → 메일로 온 결과에서 기대 수익이 0보다 큰지 확인
2. 2주 동안은 모의투자로만 사용
3. 매주 일요일 주간 요약의 성적을 보고, 필요하면 시트 "설정"에서 기준을 조정 (분기에 한 번)
