# AI 연결 수정 배포

GitHub의 `apps_script/Code.gs`를 수정하는 것만으로 Google의 배포본은 바뀌지 않습니다.

1. 기존 Apps Script 프로젝트의 `Code.gs`를 이 파일 내용으로 갱신하고 저장합니다.
2. 편집기에서 `checkAIConnection`을 실행합니다. 실행 로그의 `ok`, `provider`, `model`로 실제 응답을 확인합니다. API 키는 출력하지 않습니다.
3. `배포 → 배포 관리 → 기존 웹 앱 편집 → 새 버전 → 배포`를 선택합니다. 기존 웹 앱 URL을 유지합니다.
4. 앱의 **AI에게 묻기**에서 답변을 확인합니다.

`GROQ_API_KEY`는 스크립트 속성에 보관합니다. 선택 속성 `GROQ_MODEL`로 기본 모델을 바꿀 수 있습니다. 기본값은 `openai/gpt-oss-20b`입니다. 모델 접근 오류(404)일 때만 `llama-3.1-8b-instant`를 한 번 시도합니다. 키·한도 오류는 다음 설정된 공급자로 넘어갑니다. 계정의 실제 모델 접근 가능 여부는 연결 확인 결과로 판단합니다.

일일 매수 제한·거래 복기는 내부 자동 모의계좌에 적용됩니다. 2.19.0부터 한국투자증권 모의 주문 경로도 같은 매수 검사기를 사용하며, 증권사 계좌의 주문가능 외화·보유·확인 체결을 별도로 읽습니다. Apps Script의 수동 모의 장부와는 별개입니다. 일일 한도는 확정 순손익 기준이며 미실현 손익을 포함하지 않습니다. 일봉 보완 체결은 기존 보유 매도부터 확인하므로 실제 장중 순서와 다를 수 있습니다. 매수 봉의 목표 도달은 매수 이후인지 알 수 없어 가정하지 않고, 손절 도달은 보수적으로 반영합니다.

## 2.19.0 서버 변경

- `deskSave` / `deskNotes_`: 로그인 후 종목별 판단 기록을 `투자 판단 기록` 시트에 저장합니다. 텍스트·가격 조건은 메모이며 주문에 사용하지 않습니다.
- 수동 모의 거래의 기존 11열 뒤에 요청 ID·진입 근거 2열을 추가합니다. 기존 거래/회고는 보존합니다. 요청 ID가 같으면 재요청에도 한 번만 기록합니다.
- `kisPublic_`는 계좌 검사·접수/부분체결/완료/확인 필요 개수를 앱에 제공합니다. 계좌번호·키·토큰은 추가하지 않습니다.
- 질문 시작 종목·기준일과 투자팀 기록을 AI 문맥에 연결합니다. 기존 공급자와 비용 제한을 사용합니다.
- 이 코드를 저장하고 기존 배포의 새 버전으로 갱신해야 새 프론트의 기록 저장이 작동합니다. 추가 권한 범위나 별도 키는 필요하지 않습니다.
